# Simme Media Organiser — Free Edition

This repository contains **only the free, GPL-licensed Simme Media Organiser WordPress plugin**, version **1.3.1**.

It is a public, source-readable copy of the corrected Free plugin submitted to the WordPress.org Plugin Directory for review on **15 October 2026**. The actual WordPress.org submission ZIP is not changed by publishing this repository.

**This is NOT the commercial Simme Media Organiser Pro development repository.** The separate Pro product and the private development history are not included.

## What it does

The Free plugin provides virtual Media Library folders, protected and recoverable Trash, on-site Media Health checks, exact duplicate detection, and a non-destructive Image Studio that preserves protected Masters and supports multiple Working Versions.

See [readme.txt](readme.txt) for full features, requirements and the WordPress.org listing text.

## Installation

For WordPress plugin installation, use the official ZIP from the WordPress.org listing once the plugin is approved. This public repository is provided for source inspection and maintenance transparency.

For development testing, package the files in a directory named `simme-media-organiser`, then upload that folder as a ZIP using **Plugins → Add Plugin → Upload Plugin** on a test WordPress installation.
